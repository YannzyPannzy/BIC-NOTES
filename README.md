# bic-notes

Yannick's BIC Semester 1 notebook (College Algebra, Discrete Maths, Physics 1).

`notebook.html` is downloaded by the BIC Notes iPhone app. It is rebuilt every night from the notebook artifact with `tools/make_app_html.py`.

The three cheat sheets live in `sheets/` (Claude Docs html exports, saved with `tools/grab_exports.py`). The build puts them inside the app as their own pages, so the "Open the cheat sheet" links stay in the app instead of opening claude.ai.
