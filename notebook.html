Real numbers

L1 Course requirements · L2 Real numbers

Order of operations

brackets → powers → × and ÷ (left to right) → + and − (left to right)

12 + 3 \cdot 5 = 12 + 15 = \textcolor{#15803d}{27}

Even or odd?

  • A product is odd only if every factor is odd. So 1 \cdot 2 \cdot 3 \cdots 100 = 100! is even.
  • (-99)(-98)\cdots 99 = 0 because 0 is one of the factors, so it's even.
  • A sum is odd only if it has an odd number of odd terms.

Gauss's trick for 1 + 2 + \dots + 100: pair the first and last terms.

(1 + 100) + (2 + 99) + \dots = 101 \cdot 50 = \textcolor{#15803d}{5050}
1 + 2 + \dots + n = \frac{n(n+1)}{2} \qquad\qquad 1 + 3 + 5 + \dots + (2n-1) = n^2

Laws of real numbers (boxed in class)

\begin{aligned} a + b &= b + a & ab &= ba && \text{commutative} \\ (a + b) + c &= a + (b + c) & (ab)c &= a(bc) && \text{associative} \\ (a + b)\,c &= ac + bc && && \text{distributive} \end{aligned}

a - b \neq b - a and \frac{a}{b} \neq \frac{b}{a}. Order matters for − and ÷.

Number sets

\mathbb{N} = \{0, 1, 2, 3, \dots\} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}
  • Rational \mathbb{Q}: can be written \frac{p}{q} with p, q \in \mathbb{Z},\ q \neq 0. The decimal ends or repeats: \tfrac12,\ -\tfrac23,\ 2.25.
  • Irrational \mathbb{R} \setminus \mathbb{Q}: the decimal never ends and never repeats.
    • algebraic (a root of a polynomial): \sqrt2,\ -\sqrt3,\ \frac{1+\sqrt5}{2}
    • transcendental: \pi,\ e,\ -2\pi

Proof: √2 is irrational (proof by contradiction)

  1. Assume \sqrt2 = \frac{p}{q} with p, q \in \mathbb{Z}, and the fraction can't be simplified.
  2. Square it: 2q^2 = p^2, so p^2 is even, so p is even: p = 2r.
  3. Then 2q^2 = 4r^2 \Rightarrow q^2 = 2r^2, so q is even too.
  4. Both even means \frac{p}{q} could be simplified. Contradiction ↯

Rational and irrational

  • r = \frac{a}{b},\ s = \frac{c}{d} rational ⇒ r + s = \frac{ad + bc}{bd} is rational. Same for r - s,\ rs,\ \frac{r}{s}\ (s \neq 0).
  • r rational, t irrational ⇒ r + t is irrational. (If r + t = s were rational, then t = s - r would be rational.)
  • rt is irrational, unless r = 0.

Absolute value

|a| = \begin{cases} a & \text{if } a \ge 0 \\ -a & \text{if } a \lt 0 \end{cases}

It's the distance from 0, so it's never negative: |-3| = 3,\ |3| = 3.

The graph of |x| is a V: the line y = x for x \ge 0 and y = -x for x \lt 0.

  • |x - c| moves right by c, |x + c| moves left by c
  • |x| + c moves up by c, -|x| flips it upside down
  • |x| - 2: vertex (0, -2), crosses the x-axis at ±2

Simplifying fractions

Factorise the top and the bottom first, then cancel factors.

\begin{aligned} \frac{a^2 - 6a + 9}{a^2 - 9} &= \frac{(a - 3)^2}{(a - 3)(a + 3)} = \textcolor{#15803d}{\frac{a - 3}{a + 3}} \\[4pt] \frac{a - b}{a^2 - b^2} &= \frac{a - b}{(a - b)(a + b)} = \textcolor{#15803d}{\frac{1}{a + b}} \\[4pt] \frac{c^2 - d^2}{cx - dx} &= \frac{(c - d)(c + d)}{x(c - d)} = \textcolor{#15803d}{\frac{c + d}{x}} \\[4pt] \frac{3x^2 - 3y^2}{2x^2 - 4xy + 2y^2} &= \frac{3(x - y)(x + y)}{2(x - y)^2} = \textcolor{#15803d}{\frac{3(x + y)}{2(x - y)}} \end{aligned}

You can't cancel single terms: \frac{a + 2}{2} \neq a + 1.

Polynomial long division

From 216 \div 18 = 12: dividend, divisor, quotient, remainder.

P(x) = D(x) \cdot Q(x) + R(x)

Ex 1 a) (6x^2 - 26x + 12) \div (x - 4)

  1. 6x^2 \div x = 6x. Subtract 6x(x - 4) = 6x^2 - 24x, leaving -2x + 12.
  2. -2x \div x = -2. Subtract -2(x - 4) = -2x + 8, leaving 4.
\textcolor{#15803d}{Q(x) = 6x - 2, \quad R = 4} \qquad \text{check: } (6x - 2)(x - 4) + 4 = 6x^2 - 26x + 12 \ \checkmark

Write 0 for any missing power, e.g. 0x^2 in 3x^5 + 5x^4 - 4x^3 + 0x^2 + 7x + 3.

Horner's method (dividing by x − c)

Bring the first coefficient down, multiply by c, add to the next one, repeat. The last number is the remainder. For x + 2, use c = -2.

Ex 1 d) (3x^5 + 5x^4 - 4x^3 + 7x + 3) \div (x + 2)

\begin{array}{c|ccccc|c} & 3 & 5 & -4 & 0 & 7 & 3 \\ -2 & & -6 & 2 & 4 & -8 & 2 \\ \hline & \textcolor{#15803d}{3} & \textcolor{#15803d}{-1} & \textcolor{#15803d}{-2} & \textcolor{#15803d}{4} & \textcolor{#15803d}{-1} & \textcolor{#15803d}{5} \end{array} \qquad \Rightarrow \qquad \textcolor{#15803d}{Q(x) = 3x^4 - x^3 - 2x^2 + 4x - 1, \quad R = 5}

Multiplying and dividing

Cancel before you multiply. Dividing = multiplying by the reciprocal.

\begin{aligned} \frac{4y}{9x} \cdot \frac{6x^2}{16y^3} &= \textcolor{#15803d}{\frac{x}{6y^2}} \\[4pt] \frac{27x^3y}{72xy^3} \div \frac{15y^2}{16x} = \frac{27x^3y}{72xy^3} \cdot \frac{16x}{15y^2} &= \textcolor{#15803d}{\frac{2x^3}{5y^4}} \end{aligned}

What a set is

A collection of elements: A = \{a,\ 2,\ -3,\ x,\ \text{cat}\}.   2 \in A means 2 is in A,   1 \notin A means 1 is not in A.

It needs a clear yes/no rule: {tall people} ✗ but {people taller than 1.85 m} ✓; {fast cars} ✗ but {cars that reach 200 km/h} ✓.

Order and repeats don't matter: \{2, 5, 3\} = \{5, 2, 3\} = \{2, 5, 3, 5\}

Subsets

B \subseteq A: every element of B is in A   (x \in B \Rightarrow x \in A)

A = \{2, 5, 3\},\ B = \{2, 3\},\ C = \{2, 1\}:   B \subseteq A, but C \not\subseteq A because 1 \notin A.

Number sets

\mathbb{N} = \{0, 1, 2, 3, \dots\} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R}

s_{\text{fly}} = 100 \tfrac{\text{km}}{\text{h}} \cdot 1 \text{ h}
= \textcolor{#15803d}{100 \text{ km}}

Method: name the unknowns, write one equation per fact, solve, check the answer in the original words.

9. Rational inequalities

Must know: dividing by a negative flips the sign

\boxed{\ \textcolor{#1d4ed8}{-3x > 9 \ \big/ \div(-3) \;\Rightarrow\; x < -3}\ }
2x > 6 \ \big/ \div 2 \;\Rightarrow\; x > 3

Sign lines method

  1. Factorise the top and the bottom.

  2. Mark every zero on the number line.

  3. Draw a sign line for each factor, then multiply the signs in each interval.

  4. Read off S. Zeros of the bottom are always open; zeros of the top are closed only for ≥ or ≤.

Example (notes 28 Oct)

\frac{x^2 - 6x + 8}{x + 3} > 0
\Rightarrow\; \frac{(x - 2)(x - 4)}{x + 3} > 0
\Rightarrow\; \textcolor{#15803d}{S = \,]{-3}, 2[\ \cup\ ]4, +\infty[}

10. Square roots

Must know: definition (a ≥ 0): b = √a means b ≥ 0 and b² = a.

\boxed{\ \textcolor{#1d4ed8}{\sqrt{a^2} = |a|}\ }
(\sqrt{a})^2 = a
\sqrt{(-3)^2} = 3

Must know: rules

\textcolor{#1d4ed8}{\sqrt{a}\,\sqrt{b} = \sqrt{ab} \ \ (a, b \ge 0)}
\textcolor{#1d4ed8}{\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}} \ \ (a \ge 0,\ b > 0)}
\textcolor{#1d4ed8}{\sqrt{a^n} = (\sqrt{a})^n \ \ (a \ge 0)}

Watch out

\textcolor{#dc2626}{\sqrt{9 + 16} = 5 \neq \sqrt{9} + \sqrt{16} = 7}
\textcolor{#dc2626}{\sqrt{(-2)(-8)} = 4, \text{ but not } \sqrt{-2}\,\sqrt{-8}}

Shortcuts: spot (a ± b)² under the root, and split off the biggest square factor.

\sqrt{y^2 + 6y + 9} = \textcolor{#15803d}{|y + 3|}
\sqrt{12} - \sqrt{27} + \tfrac12\sqrt{48} = 2\sqrt3 - 3\sqrt3 + 2\sqrt3
= \textcolor{#15803d}{\sqrt3}

3. Counting elements

Two sets

\begin{aligned} \text{only A:} \quad & |A \setminus B| = |A| - |A \cap B| \\ \text{exactly one:} \quad & |A \cup B| - |A \cap B| \\ \text{neither:} \quad & |U| - |A \cup B| \end{aligned}

Example (sheet 2): 35 people, 21 drink Coca-Cola, 19 Fanta, 12 both.

\text{at least one} = 21 + 19 - 12 = \textcolor{#15803d}{28}
\text{neither} = 35 - 28 = \textcolor{#15803d}{7}
\text{exactly one} = 28 - 12 = \textcolor{#15803d}{16}

Three sets

\boxed{\ \begin{aligned} \textcolor{#1d4ed8}{|A \cup B \cup C|} &\textcolor{#1d4ed8}{= |A| + |B| + |C|} \\ &\textcolor{#1d4ed8}{\quad - |A \cap B| - |A \cap C| - |B \cap C|} \\ &\textcolor{#dc2626}{\quad + |A \cap B \cap C|} \end{aligned}\ }

Venn method for word problems

  1. Fill the middle (all three) first.

  2. Then each pair, minus the middle.

  3. Then each "only" part.

  4. Then the outside (neither).

  5. Unknown? Use x and make all regions add up to |U|.

Watch out: "A and B" includes the middle. "Only A and B" doesn't. "Or" means at least one.
