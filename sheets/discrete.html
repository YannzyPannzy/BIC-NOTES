2. Operations and laws

De Morgan

\boxed{\ \textcolor{#1d4ed8}{(A \cup B)' = A' \cap B' \qquad\quad (A \cap B)' = A' \cup B'}\ }

Taking the complement of a bracket flips ∪ ↔ ∩.

Difference and symmetric difference

A \setminus B = A \cap B' \qquad\qquad A \,\triangle\, B = (A \cup B) \setminus (A \cap B)

Distributive laws

A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \qquad\qquad A \cup (B \cap C) = (A \cup B) \cap (A \cup C)

Simplifying

\begin{aligned}
A \cup A' &= U & A \cap A' &= \emptyset & (A')' &= A \\
A \cup \emptyset &= A & A \cap U &= A & A \cup (A \cap B) &= A
\end{aligned}

If A ⊆ B

A \cup B = B \qquad A \cap B = A \qquad A \setminus B = \emptyset

Order matters for A \ B and A × B (the others don't care).

3. Counting elements

Two sets

\boxed{\ \textcolor{#1d4ed8}{|A \cup B| = |A| + |B|} \textcolor{#dc2626}{\,- |A \cap B|}\ }
\begin{aligned}
\text{only A:} \quad & |A \setminus B| = |A| - |A \cap B| \\
\text{exactly one:} \quad & |A \cup B| - |A \cap B| \\
\text{neither:} \quad & |U| - |A \cup B|
\end{aligned}

Example (sheet 2): 35 people, 21 drink Coca-Cola, 19 Fanta, 12 both.

\text{at least one} = 21 + 19 - 12 = \textcolor{#15803d}{28} \qquad \text{neither} = 35 - 28 = \textcolor{#15803d}{7} \qquad \text{exactly one} = 28 - 12 = \textcolor{#15803d}{16}

Three sets

\boxed{\ \textcolor{#1d4ed8}{|A \cup B \cup C| = |A| + |B| + |C| - |A \cap B| - |A \cap C| - |B \cap C|} \textcolor{#dc2626}{\,+ |A \cap B \cap C|}\ }

Venn method for word problems

  1. Fill the middle (all three) first.

  2. Then each pair, minus the middle.

  3. Then each "only" part.

  4. Then the outside (neither).

  5. Unknown? Use x and make all regions add up to |U|.

Watch out: "A and B" includes the middle. "Only A and B" doesn't. "Or" means at least one.

4. Subsets and products

Number of subsets (class, 20 Oct)

\boxed{\ \textcolor{#1d4ed8}{\text{a set with } n \text{ elements has } 2^n \text{ subsets}}\ } \qquad \{a, b, c\} \rightarrow \textcolor{#15803d}{2^3 = 8}

The empty set and the set itself both count.

Counting elements when sets are inside sets

|\{\}| = 0 \qquad \textcolor{#dc2626}{|\{\{\}\}| = 1} \qquad |\{1, 2, \{3, 4\}\}| = 3

Element vs subset

a \in A \iff \{a\} \subseteq A

Cartesian product (all ordered pairs)

A \times B = \{(a, b) \mid a \in A,\ b \in B\} \qquad \boxed{\ \textcolor{#1d4ed8}{|A \times B| = |A| \cdot |B|}\ }

Smallest and largest sizes (with |A| = a, |B| = b)

\begin{aligned}
0 \le\ &|A \cap B| \le \min(a, b) \\
\max(a, b) \le\ &|A \cup B| \le a + b
\end{aligned}

The extremes happen when the sets don't overlap, or when one sits inside the other. If a universal set U is given, the intersection is at least a + b − |U|.

5. Decimals, exact values and regions

Repeating decimal to fraction (method from class)

x = 1.\overline{5} \;\Rightarrow\; 10x = 15.\overline{5} \;\Rightarrow\; 9x = 14 \;\Rightarrow\; \textcolor{#15803d}{x = \frac{14}{9}}

Multiply by 10 for one repeating digit, 100 for two, then subtract.

Quick version: the repeating part over the same number of 9s.

0.\overline{5} = \textcolor{#15803d}{\frac{5}{9}} \qquad 0.\overline{25} = \textcolor{#15803d}{\frac{25}{99}} \qquad 1.\overline{25} = 1 + \frac{25}{99} = \textcolor{#15803d}{\frac{124}{99}}
